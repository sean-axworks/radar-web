# Radar 웹 MVP

GrantRadar와 BidRadar 공고를 한곳에서 보고, 상세 페이지에서 해당 공고의 사업비를 시뮬레이션하는 정적 웹 포털입니다. POA Lite 공통 지침을 적용해 `C:\POA\projects\radar-web`에서 로컬 개발과 검증을 진행했습니다.

## 실행

Node.js 22.18 이상에서 프로젝트 폴더를 열고 실행합니다.

```powershell
npm ci
npm run dev
```

[http://localhost:3000](http://localhost:3000)에서 확인할 수 있습니다. PowerShell에서 스크립트 실행이 제한된 경우 `npm.cmd ci`, `npm.cmd run dev`를 사용하세요.

`npm test`는 계산 규칙을 확인하고, `npm run lint`는 ESLint 검사를 실행합니다. `npm run build`는 TypeScript를 검사하고 홈, 계산기, 각 공고 상세 페이지를 `out/`에 정적 HTML로 생성합니다.

## 공고 데이터

`data/grants.json`과 `data/bids.json`에 각 3건의 초기 데이터를 넣었습니다. JSON을 수정한 뒤 다시 빌드하면 목록과 상세 페이지에 반영됩니다. 각 배열의 첫 번째 공고를 홈 하이라이트로 표시합니다.

- `deadline`은 날짜 또는 한국 표준시(+09:00)를 포함한 ISO 날짜·시간입니다.
- `max_grant_amount`는 원 단위입니다. 국책과제에는 정부지원금 상한, 공공입찰에는 시뮬레이션용 부가세 제외 추정가격을 저장합니다.
- `gov_ratio`는 총사업비 대비 정부지원비율, `cash_ratio`는 민간부담금 대비 최소 현금비율입니다. `0.75`는 75%입니다.
- `summary_3lines`는 3개 문자열의 배열입니다. 합성 예시는 `is_demo: true`, `source_url`이 공고 사이트나 목록이면 `source_is_listing: true`를 사용합니다.
- KHIDI와 KOICA는 공개 공고 사례입니다. KOICA의 나라장터 원문은 서비스 접속 상태에 따라 로그인을 요청할 수 있으며, 직접 검색할 때 사용할 공고번호를 상세에 표시합니다.

## 계산 기준

- 총사업비 기준은 정부지원금을 원 단위로 내림하고, 정부지원금 기준은 필요한 총사업비를 올림합니다.
- 민간현금 최소액은 민간부담금에 현금비율을 곱한 뒤 원 단위로 올림합니다. 민간현물은 현금을 최소액으로 계상한 시나리오입니다.
- 인건비는 총사업비에 입력 비율을 적용합니다. 연구수당 상한은 그 인건비의 20%를 가정합니다.
- 간접비는 공고 기준 직접비에 사용자가 지정한 간접비율을 적용합니다. 직접비를 입력하면 한도가 계산됩니다. 기본 간접비율 5%는 예시입니다.
- 엑셀은 브라우저에서 생성한 입력 및 결과 스냅샷입니다. 실제 제출 양식과 비용 인정 기준은 공고 원문을 확인하세요.
