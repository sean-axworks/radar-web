# Radar 웹 MVP

GrantRadar와 BidRadar 공고를 한곳에서 보고, 상세 페이지에서 해당 공고의 사업비를 시뮬레이션하는 정적 웹 포털입니다. POA Lite 공통 지침을 적용해 `C:\POA\projects\radar-web`에서 로컬 개발과 검증을 진행했습니다.

## 실행

Node.js 22.18 이상에서 프로젝트 폴더를 열고 실행합니다.

```powershell
npm ci
npm run dev
```

[http://localhost:3000](http://localhost:3000)에서 확인할 수 있습니다. PowerShell에서 스크립트 실행이 제한된 경우 `npm.cmd ci`, `npm.cmd run dev`를 사용하세요.

`npm test`는 계산 규칙을 확인하고, `npm run lint`는 ESLint 검사를 실행합니다. `npm run build`는 TypeScript를 검사하고 홈, 계산기, 각 공고 상세 페이지를 `out/`에 정적 HTML로 생성합니다.

## 공고 데이터

`data/grants.json`과 `data/bids.json`을 수정한 뒤 다시 빌드하면 목록과 상세 페이지에 반영됩니다. 국책과제 목록과 홈 하이라이트는 `deadline`이 한국시간 기준으로 지난 공고를 숨깁니다. 날짜만 있으면 해당 날짜가 끝날 때까지 표시하며, 마감이 미확인인 공고는 원문 확인 안내와 함께 표시합니다. 숨겨진 공고의 상세 주소는 계속 열 수 있습니다.

- `deadline`은 날짜 또는 한국 표준시(+09:00)를 포함한 ISO 날짜·시간입니다.
- `max_grant_amount`는 원 단위입니다. 국책과제에는 정부지원금 상한, 공공입찰에는 시뮬레이션용 부가세 제외 추정가격을 저장합니다.
- `gov_ratio`는 총사업비 대비 정부지원비율, `cash_ratio`는 민간부담금 대비 최소 현금비율입니다. `0.75`는 75%입니다.
- `summary_3lines`는 3개 문자열의 배열입니다. 합성 예시는 `is_demo: true`, `source_url`이 공고 사이트나 목록이면 `source_is_listing: true`를 사용합니다.
- 자동 수집에서 마감이나 산정 조건을 확인할 수 없으면 `deadline`, `max_grant_amount`, `gov_ratio`, `cash_ratio`에 `null`을 사용할 수 있습니다. 계산기에 빈 입력으로 표시됩니다.
- KHIDI와 KOICA는 공개 공고 사례입니다. KOICA의 나라장터 원문은 서비스 접속 상태에 따라 로그인을 요청할 수 있으며, 직접 검색할 때 사용할 공고번호를 상세에 표시합니다.

## 계산 기준

- 총사업비 기준은 정부지원금을 원 단위로 내림하고, 정부지원금 기준은 필요한 총사업비를 올림합니다.
- 민간현금 최소액은 민간부담금에 현금비율을 곱한 뒤 원 단위로 올림합니다. 민간현물은 현금을 최소액으로 계상한 시나리오입니다.
- 인건비는 총사업비에 입력 비율을 적용합니다. 연구수당 상한은 그 인건비의 20%를 가정합니다.
- 간접비는 공고 기준 직접비에 사용자가 지정한 간접비율을 적용합니다. 직접비를 입력하면 한도가 계산됩니다. 기본 간접비율 5%는 예시입니다.
- 엑셀은 브라우저에서 생성한 입력 및 결과 스냅샷입니다. 실제 제출 양식과 비용 인정 기준은 공고 원문을 확인하세요.

## 봇 연동

GrantRadar와 BidRadar의 로컬 `.env`에서 `RADAR_WEB_DIR`에 이 저장소의 절대 경로를, `RADAR_WEB_BASE_URL`에 공개 도메인을 지정합니다. 두 봇을 실행하는 계정은 이 저장소의 `main` 브랜치와 `origin/main`에 접근할 수 있어야 합니다.

봇은 선별된 공고를 `tools/sync_notices.py`에 넘깁니다. 같은 저장소를 사용하는 두 봇은 동기화 순서를 조정합니다. 실패한 공고는 저장소 내부의 로컬 대기열에 남아 같은 봇의 다음 실행에서 다시 시도됩니다. 자동 커밋에는 대상 공고 JSON만 포함됩니다. 해당 JSON에 로컬 편집이 있거나 관련 없는 미푸시 커밋이 있으면 웹 작업은 대기합니다.

실행 보고의 웹 반영 건수는 GitHub 푸시 기준입니다. Vercel은 이후 정적 페이지를 빌드하므로, 푸시 직후에는 신규 공고 링크가 아직 열리지 않을 수 있습니다.

## 방문 및 전환 측정

- Vercel 프로젝트의 **Analytics**에서 Web Analytics를 활성화하면 방문과 페이지뷰를 확인할 수 있습니다.
- GA4는 웹 데이터 스트림의 측정 ID `G-…`를 Vercel의 `NEXT_PUBLIC_GA_ID`에 추가한 뒤 재배포하면 시작됩니다. 로컬에서는 `.env.local`에 같은 변수를 설정할 수 있습니다.
- GA4에서 `calculator_used`는 유효한 입력 변경 후 계산기별·탭 세션별 한 번, `excel_download`는 내보내기 클릭 시점, `source_link_click`은 공고 원문이나 텔레그램 채널 링크 클릭 시 기록합니다.


## 지원금액 정규화

`tools/grant_amounts.py`는 봇의 신규 지원사업 JSON을 웹에 반영할 때
`budget_text`에서 누락된 `max_grant_amount`만 보완합니다. 기존 숫자와
`gov_ratio`, `cash_ratio`는 유지합니다. 원·만·백만·천만·억 단위와 범위 상한을
처리하며, 기관/과제/개소당 금액을 전체 배정액보다 우선합니다.
총액을 모집 수로 나누지 않고, 쿠폰·상품권·임대료·보증금 등은 제외합니다.
현물 지원액과 조건부/추정 상한도 원문 설명을 그대로 남긴 계산기 입력값이며,
현금 지급 확정액을 의미하지 않습니다.

기존 데이터의 누락값은 저장소 루트에서 `python -B tools/normalize_grants.py`로
같은 파서를 적용합니다. 봇과 동일한 SQLite writer lock을 잡고 로컬 JSON만
수정하며 커밋·푸시는 하지 않습니다. 재실행은 멱등적입니다.


## 지원·현금 비율과 비교 계산

JSON의 `gov_ratio`는 지원금/총사업비, `cash_ratio`는 현금 최소액/민간부담금
(지방비 등 대응부담 포함)의 0~1 분수입니다. 화면은 100을 곱한 %를 사용합니다.
지원금 기준 총사업비는 지원금÷지원비율을 원 단위 올림하며, 현금 최소액은
민간부담금×현금비율을 원 단위 올림합니다. 기존 `0.5 / 1.0` 정의는 유지합니다.
민간 협동조합의 현물 지원에도 맞도록 화면 용어는 ‘지원금·지원비율’로 표시합니다.

`tools/grant_ratios.py`는 저장된 지원내용·요약에서 명시된 자금 분담 조건만
분석합니다. 인건비·간접비·평가배점·무료 참가·지원금 사용처 비중은 근거가 아닙니다.
기존 숫자는 보존하고 신규 sync 및 같은 백필 명령에 공통 적용합니다.
검토한 원문 근거는 코드의 `REVIEWED`에 공고 ID·저장문구 SHA-256 일치 조건과 함께 기록합니다.

- `k-startup-179682`: ‘총 5,000만 원 상당의 공간 맞춤형 방탈출 게임을 무상으로 제작해 드립니다.’
  ([원문](https://www.k-startup.go.kr/web/contents/bizpbanc-ongoing.do?schM=view&id=179682)).
  저장 요약의 ‘무상 제작하는 민간 사업’과 사용자가 확인한 자부담 없음에 따라
  지원비율 1, 현금비율 0을 적용합니다. 현금 지급이 아닌 현물 제작 지원입니다.
- `khidi-48951946`: ‘지방비는 국비 대비 1:1 이상 매칭하며, 이 중 현금 50% 이상 매칭 필수’
  ([동일 공고 공식 게시문](https://www.khidi.or.kr/board/view?linkId=48951946&menuId=MENU01108)).
  최소 매칭 시나리오로 국비/총사업비 0.5, 지방비 중 현금 최소비율 0.5를 적용합니다.
  지방비를 더 매칭하면 실제 지원비율은 낮아질 수 있습니다.

비율 미확인 공고는 null을 유지하고 화면에서 누락된 항목을 안내합니다.
‘지원 100% / 70:30 / 50:50’ 버튼은 사용자가 선택하는 비교 가정이며 공고 조건이나
저장 데이터가 아닙니다. 100%는 현금부담 0원, 나머지는 현금비율이 비었을 때만
민간부담금의 10%를 가정하고 기존 입력값은 유지합니다.
